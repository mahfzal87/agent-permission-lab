    A stop button needs a boundary.

    A queued request has not yet changed the world. An authorisation decision must still be valid when the protected side effect happens. A previously accepted request is not a permanent permission slip.

    What this does not prove

    This single-threaded teaching model makes the decision and write one operation. Real systems need a defined linearisation point, atomic checks or equivalent fencing, propagation limits, and tests for races. Revoking authority does not undo a payment already committed.
