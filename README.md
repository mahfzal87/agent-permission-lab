# Agent Permission Lab
A self-contained educational simulation by Ahmad Afzal. Open index.html in a browser. No dependencies, API keys, telemetry, network calls or real payments.

Compare task-start authorisation with a version check at commit. Queue, revoke, then attempt a £40 refund. Reset and compare the other strategy. Also test the active-authority path.

This is a teaching model, not production security middleware. It does not model distributed races, token validation, partial failures or cancellation of a committed transaction. All amounts and evidence events are synthetic. Real enforcement must live at a trusted boundary.
